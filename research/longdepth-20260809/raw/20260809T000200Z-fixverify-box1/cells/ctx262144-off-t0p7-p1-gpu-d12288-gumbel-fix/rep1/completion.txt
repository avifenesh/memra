<h2>1. System Overview</h2>
<p>Atlas is a modular operations platform designed for high-throughput data processing and real-time analytics. It provides a unified interface for managing clusters, pipelines, and user permissions across multiple environments.</p>
<p>The core runtime is written in portable C with optional bindings for Python and JavaScript. Configuration is driven by hierarchical YAML files validated against JSON schemas.</p>
<dl>
<dt>Architecture</dt><dd>Microservices with event-driven communication</dd>
<dt>Uptime SLA</dt><dd>99.98 percent over trailing twelve months</dd>
<dt>Data format</dt><dd>Protocol Buffers v3 and Apache Avro</dd>
<dt>Scalability</dt><dd>Horizontal scaling to 1024 nodes per cluster</dd>

<h2>2. Installation</h2>
<p>Installation requires a minimum of three nodes for quorum. Use the provided bootstrap script to initialize the first control plane node. Ensure all machines have synchronized clocks via NTP.</p>
<p>The installer validates hardware prerequisites including CPU flags, memory size, and disk throughput. Failures are logged to /var/log/atlas/install.log and must be resolved before proceeding.</p>
<dl>
<dt>OS support</dt><dd>Linux kernel 5.4+, Ubuntu 22.04, RHEL 9</dd>
<dt>Dependencies</dt><dd>containerd, iptables, socat, curl</dd>
<dt>Network</dt><dd>TCP 6443, 2379-2380, 10250</dd>
<dt>Disk</dt><dd>Minimum 100 GB SSD per node</dd>

<h2>3. Configuration</h2>
<p>Configuration files reside in /etc/atlas/. The primary file config.yaml controls feature flags, resource limits, and module loading. Changes require a rolling restart to take effect.</p>
<p>Use atlasctl diff to preview changes before applying. The system maintains the previous three revisions and supports instant rollback via atlasctl rollback.</p>

<section id="section-4">
<h2>4. User Management</h2>
<p>User accounts are stored in an integrated LDAP directory with optional MFA. Administrators can create, suspend, and delete accounts via the CLI or web console.</p>
<p>Password policies enforce minimum length, complexity, and rotation every 90 days. Account lockout occurs after five failed attempts for 15 minutes.</p>
<dl>
<dt>Default admin</dt><dd>atlas-admin</dd>
<dt>MFA</dt><dd>TOTP required for privileged actions</dd>
<dt>Lockout</dt><td>5 failures / 15 minutes</dd>
