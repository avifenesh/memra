The original four #541 criteria cover complete pre-upload binding, contextual malformed-checkpoint refusal, explicit tied-head ownership, and intended-native format/model regressions. The strict same-executable qualification bootstrap is separate backlog #625. Unsupported/unqualified routes retain explicit refusal; Legacy results never become qualified execution.

This preparation adds a real-container native loader gate. The generator produces20 tiny GGUF/HF artifacts: seven valid controls and thirteen malformed controls. Both dense and hybrid entry points are selected explicitly, giving40 native cases. Valid cases cover separate/tied heads, GGUF Q5_K, small HF BF16 with the existing F32 expansion, and an HF NVFP4 query with its macro and embedded block-scale bytes. Malformed cases cover missing/extra tensors, wrong shapes/storage, untied missing output, duplicate GGUF names, ambiguous HF aliases and missing NVFP4 auxiliaries.

The CPU preparation verifies complete canonical binding/runtime views for these real files. The native test uses the actual loader, existing allocation/DtoH trace hooks, physical lease verifier and GPU output readback. Malformed loads must have no Engine allocation/readback trace inside the marked root boundary and the declared contextual error. Positive loads must exercise the observation channel and return the exact expected output bytes/owner. The NVFP4 query additionally checks actual representation, macro, byte count and code/scale counts; detailed repack arithmetic remains covered by the separate native repack gate. No new production API or admission exception is added.

These before/after checks detect drift; they are not an atomic snapshot against an adversarial writer. Keep the selected inputs immutable throughout the owned job.

Success publication uses the shared cancellation guard. The outer lease remains held through cleanup; this controller cannot release it or substitute a legacy lock. Parent SIGKILL, kernel hangs and descendants escaping the owned process group require an external supervisor and are outside this userspace guarantee. Each result remains evidence for this integration-test ELF, not server qualification.
