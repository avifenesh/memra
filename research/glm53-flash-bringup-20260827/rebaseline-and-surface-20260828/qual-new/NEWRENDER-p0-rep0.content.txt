Got it — so it's a **captured-context brain** driven by a model, not a rewrite of a Rust tool. Let me reflect the spec back before building:

**What I understand:**

- **CLI** (I'd suggest Node or Python — pick one), calling a model API for all the "understanding" work — no rigid parsers.
- **One command, minimal input.** You type a few sentences (or fragments). The agent figures out: is this a new project, an update to an existing one, an idea bolted onto an old one, an answer to a maintainer issue, a new todo, a deferral?
- **Storage = compact JSONL per context.** Each tool/session you use (shell, editor, another CLI) leaves traces; the agent captures only the **relevant** lines, compresses them into the right project's jsonl file.
- **Interactive capture loop.** After ingesting, the agent asks if you want to elaborate on anything notable — as **numbered options (1, 2, 3...)** so you just press a key. It never forces you to type long answers unless you *want* to.
- **Context-switching is the core model, not an edge case.** So the state needs:
  - **Projects** (5-6 active, with a current-focus pointer)
  - **Inbox / ideas** (dropped thoughts, original intent preserved — because you know you'll forget *why* you started project X)
  - **Deferred / v2** (separate from "todo", or it pollutes the queue)
  - **Energy-tagged small tasks** — when you want frictionless+fun, you call the tool and it serves you low-energy items instead of looking at the big board
  - **Issues / contributions / maintainer replies** as their own lanes
- **The killer command:** "new" — you always want to start something new. So it must never guilt you into finishing, just park and track.

**Sketch of how it'd work:**

```
$ park                      # opens capture: type a few sentences
  → model classifies → routes to project X jsonl
  → "Noted 3 things. Want to clarify?
     1. The API design for X seems half-thought
     2. New idea 'foo bot' has no intent recorded
     3. Looks fine
     > 1
  → (model asks one question, you can answer in a few words or skip)
$ switch    # shows active projects → pick one, restores full compact context
$ small     # low-energy tasks, frictionless fun stuff
$ v2        # deferred features browsable, agent gently resurfaces old ones
$ inbox     # ideas with their original 'why' attached
```
