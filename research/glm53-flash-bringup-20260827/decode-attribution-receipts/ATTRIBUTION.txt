WHAT THE 17 ms IS (source, not speculation)
  glm5_next is denied EVERY fused MoE arm:
    - config.rs swiglu_clamped_at() is TRUE for every glm5 layer (swiglu_limit 10.0, PRE form).
      That single predicate denies grouped-decode (gdec), moe_pairs_silu_mul and moe_ffn_dev,
      whose epilogues hardcode plain silu(gate)*up.
    - hybrid_forward.rs:7048 `no_macros` additionally denies gdec: compressed-tensors NVFP4
      carries a per-expert weight_scale_2 the fused kernels do not fold.
    - moe_ffn_dev debug_asserts sigmoid_router().is_none(); glm5 routes sigmoid/noaux_tc.
  So every token-layer runs the per-expert sequential loop: 8 experts x ~5 launches, plus a
  router GEMV, a host DtoH of the router logits and a stream sync, x42 layers. Estimated launch
  census ~3200/token (~1750 of them the MoE loop); 17.1 ms / 3200 = ~5.3 us, which is exactly
  kernel-launch latency. The engine's own comment for the dev path names the same cost: "removes
  the per-layer router DtoH + stream sync — the per-token host stall that dominated the 35B
  decode wall".
  NOTE the ordering constraint: gdec only fires when ALL 24 blocks of a token-layer are already
  cache-resident. At the measured 17.5% miss rate P(all 24) = 0.83^24 ~ 1.2%, so a fused epilogue
  is worth almost nothing until full residency lands. Residency is the keystone, not the epilogue.

BYTE IDENTITY. Five arms — two transports, two slot counts, two boots — produce the IDENTICAL
greedy text on p5 (fd006d0d50eb59b5) and the identical seeded sampled text (7db18bc5e2a04140).
MEMRA_ST_PINNED and MEMRA_MOE_SLOTS are therefore proven non-numeric here, exactly as the code
claims (same HostExps bytes; only the copy's provenance and the residency set change).
MEMRA_BF16_MMV IS a numeric-class door and its sha differs (ca1e3cc2e4ea7104) — stable across
both of its arms, but it needs its own documented acceptance (run-gen argmax gate + boot battery)
and owner ratification before any default change.

INTERLEAVE. The arms are process-level env (OnceLock), so they cannot alternate inside one
server; the interleave unit is a BOOT. A1/A2 were alternated across boots with 4 reps inside
each. Reproducibility: A1 8.538 vs A1R 8.506 (0.4%); A2 20.348 vs A2R 20.347 (0.005%). Deviation
from the strict x5 request-level protocol is stated, not hidden; the effect is 2.4-3.0x.

CONTINUITY with the bring-up receipts. BRINGUP.md's 19.70 greedy / 12.70 sampled came from a
31-token synthetic prompt ("Write one short sentence about the sea.") with reasoning_effort
UNPINNED. Re-run here as its own cell it reproduces: A2LOW sea sampled 12.02 (vs the banked
12.70). That prompt is 31 tokens, below the 64-token prefix-cache floor, so every rep re-prefills
and its tok/s is prefill-dominated, and it warms one narrow expert set. The 8.5 tok/s real-prompt
baseline is not an instrument regression — it is what a real agentic prompt costs.
