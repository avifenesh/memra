you crashed Root cause
.venv was deleted while the gateway process (started May 10) was still running. The Python binary kept executing via mmap, but lazy open() on files inside the venv (like certifi/cacert.pem) failed → FileNotFoundError from ssl.create_default_context inside httpx, on every new AnthropicBedrock client init.
What I did
1. Recreated the venv: uv sync --frozen --all-extras (full --all-extras failed on mistralai resolver — used frozen lockfile to bypass).
2. Killed the broken process (PID 3879941) with SIGKILL after SIGTERM didn't take.
3. Relaunched in a new detached tmux session hermes-gateway (was running in a ghostty terminal scope before — would have died if you closed that window).
