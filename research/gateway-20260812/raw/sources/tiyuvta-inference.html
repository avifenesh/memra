One open-weight thinking model. A 262,144-token context window. An OpenAI-style chat-completions endpoint. Keys are issued manually and the trial costs $0. That is the lab's current hosted offering; paid plans, self-service, current performance claims, and an SLA are not live.

fig. 01 · the current contract

Exact model id

Send stepfun/step-3.7-flash. No other model or alias is advertised. Check the public catalog endpoint before depending on the trial.

Text and thinking

Step-3.7-Flash is a thinking model. The upstream weights support more modalities, but this endpoint currently reports text input to text output. Image and video input are not part of this trial contract.

256k context

The live catalog reports 262,144 tokens. A separate maximum-completion value is not published, so do not assume the entire window is available for output.

fig. 02 · how access works

1. Describe the workload

Send a short request through the access page. Avi reads every request; there is no automated approval or promised response time.

2. Receive a trial key

Keys are created and delivered manually. The rate limit for a key is shared when access is issued; there is no public default quota.

3. Send a basic request

Follow the quickstart with the exact model id. There is no account dashboard or automatic conversion to billing.

fig. 03 · what trial means here

Useful for evaluation. Not a production dependency yet.

  • No uptime percentage or latency target is published.
  • No current Step-3.7-Flash throughput or determinism result is published.
  • There is no self-serve account, billing, key rotation, or recovery UI.
  • Limits are assigned per key and shared when access is granted.

Keep a fallback. If a result matters to your system, store the model id, request, response, and time with your own run record.

fig. 04 · who this trial is for

Developers testing a thinking model

Bring an existing OpenAI client, swap the base URL and model id, and compare the model on your own prompts.

Small teams with long inputs

The 256k window is relevant to repositories, long documents, and agent histories. Test quality and latency on your actual workload.

Self-hosters reading the engine

The model weights and the memra engine are public. The hosted trial is a way to inspect the serving surface before deciding what to run.

This is not a consumer chat app, a broad model marketplace, or an enterprise service with procurement and compliance guarantees.

fig. 05 · public components

memra

The inference engine is a public Rust and CUDA project under the MIT license. Its repository contains engine tests and dated research runs. Those older measurements are not live trial performance.

Step-3.7-Flash weights

StepFun publishes the model weights under Apache-2.0. The upstream model is multimodal; tiyuvta's current endpoint is text-only.

fig. 06 · trial data and price

Trial data may be retained

Prompts and responses may be used for training or evaluation. Do not send secrets or data you cannot share under the trial data policy.

The trial is $0

No payment is collected and there is no automatic paid conversion. Paid pricing is not published. The pricing page records that plainly.

faq

Can I use the OpenAI SDK?

Yes for the basic chat-completions request in the quickstart. Wider parameter compatibility is not promised on this site yet.

Why only one model?

That is the live deployment. Planned models and old Qwen experiments are not listed as available.

What are the rate limits?

They are set per key and disclosed at issuance. There is no public default quota.

Can I use this in production?

Treat it as a trial. There is no SLA, public uptime history, or continued-availability promise.

If this fits a real workload, you are welcome to try it.
