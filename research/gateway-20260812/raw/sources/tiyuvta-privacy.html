Privacy & data policy

2026-08-09

Who operates this service

Avi Fenesh operates tiyuvta. Contact: [email protected].

What the API processes and records

The service processes the prompt you send and the model response it generates. It also records operational metadata: request id, timestamp, model id, token counts, request status, and the account that made the request.

The API is behind Cloudflare. Cloudflare processes connection information, including IP addresses, to terminate TLS, route traffic, and apply network security controls.

Trial prompts and responses may be retained. Do not send secrets, regulated data, personal data you are not allowed to share, or any content you do not want retained under this trial policy.

Training

Trial prompts and responses may be used to train or evaluate tiyuvta models. This is part of the $0 trial, not an opt-in paid feature.

There is no paid no-training tier today. A future paid tier may use a different policy, but it is not available and this page does not promise its terms.

No third-party trackers

This website sets no third-party trackers, no advertising pixels, and no cross-site cookies. The current build loads no analytics script.

Data retention

Operational metadata (the fields listed above) is retained for 12 months for service operation and abuse investigation, then deleted.

Trial prompt and response bodies do not have a shorter automatic deletion window promised today. You can request deletion, but data already used in a training or evaluation artifact may not be reversible.

Subprocessors

Cloudflare provides the public network edge. GPU inference runs on rented compute infrastructure. These providers process data needed to route or run requests under their own service terms. Traffic is TLS-encrypted between your client and the public API edge.

Your requests

To ask what is held about your account, or to request deletion, email [email protected]. Include the email address used for access and any request ids that help locate the records. Deletion requests can cover account records, metering metadata, and trial prompt or response bodies that can still be identified.

Changes

Material changes are posted on this page with a new effective date before they apply to new trial use.
