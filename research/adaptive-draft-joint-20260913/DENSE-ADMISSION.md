# Dense training after the insufficient-support result

The first fresh admission test remains a recorded failure: learned token tables
made no useful actions, while highest-score selection repaired19 sampled states.
The context regression was not fitted: only six nontrivial training interventions
were available, below the preregistered minimum of eight.

Collect every reached block (probe cadence1) on only the original16 training and
16 calibration prompts. Do not train on the first fresh test. Keep the same head,
32-candidate suffix-assisted source, K4, zero confidence and frozen live rows.
Record full and bounded probes separately with full output identity. Dense
instrumentation is an offline data-collection cost, not the normal16-block cost.

Refit exactly the existing table/context model classes, features, state weights,
ridge penalties and threshold grid. The candidate source remains fixed from the
earlier calibration choice. Freeze the new checkpoint before collecting a second
fresh24-prompt test. Use six further families: chronology reconciliation, unit
conversion, finite-grammar parsing, taxonomy assignment, feature comparison and
reference resolution. Report four cases within each family as correlated cases.

The first fresh set is retained as historical evidence and is not reused as the
new test or as training input. Advance only a learned model that beats no-op,
frequency and highest-score selection on the second test. An abstaining model
does not establish a useful online head policy. No confidence/depth combination
is admitted as a substitute for this gate.
