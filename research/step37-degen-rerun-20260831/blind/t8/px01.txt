## Triage & Investigation
### Triage Verdict
This is a confirmed bug, not a question — no additional clarification from the reporter is required. The issue correctly identifies two broken links in the Agnix JetBrains Marketplace listing.
### Root Cause
Stale hardcoded URLs in the plugin's publish configuration and in-app UI, leftover from before the project was transferred to the `agent-sh` GitHub org:
1. Documentation link points to an expired Netlify site (`https://old-agnix-docs.netlify.app`) that returns 404
2. Source code link points to an archived pre-move repository (`https://github.com/agnix-dev/agnix`) that is no longer active

---
## Implementation (Branch: `fix/marketplace-broken-links-1099`)
All changes are minimal, targeted, and non-breaking:
| File Changed | Change Made |
|--------------|-------------|
| `build.gradle.kts` | Updated `jetbrains.marketplace` config: <br> - `documentationUrl` → `https://agent-sh.github.io/agnix/` (live GitHub Pages docs site) <br> - `repositoryUrl` → `https://github.com/agent-sh/agnix` (canonical active repo) |
| `.github/workflows/publish-to-marketplace.yml` | Updated `DOCS_URL` and `REPO_URL` environment variables to match the new correct values, so all future releases inherit the fixed links |
| `src/main/kotlin/com/agent/agnix/ui/AboutDialog.kt` | Updated the in-app "Source Code" hyperlink to point to the new canonical repo, fixing broken links inside the plugin itself |
