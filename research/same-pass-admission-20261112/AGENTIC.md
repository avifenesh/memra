# Agentic replay at c = 2 (memra#1255)

The 29-turn agentic workload of the 2026-11-05 decision cell (8 sessions, tool calls, thinking
on, T = 1.0, seed 1234, 768 new tokens at most), two closed-loop users. Server: Qwen3.8-27B
NVFP4 + Q5_K, DFlash2 drafter, FR-Spec trim, `MEMRA_MTP_SKIP=1`, ctx 32,768, 8 sessions, prefix
cache 4,000 MB, `MEMRA_KV_HOST_MB=0`. One fresh boot per row, rows in run order; generated by
`harness/ab-table.py`. Settle waits are `/metrics` `admission_settle_waits` (passes); the
settled column counts `[admission] settled:` lines and sums their milliseconds (from a request's
first settle wait to its admission, so it includes any VRAM defer that followed). TTFT
percentiles are over the timed turns (completion tokens > 1). Text identity compares each
turn's text sha against the first boot of the table: the workload is seeded, so equal programs
write equal text.
