# B200

NVIDIA's B200 (Blackwell datacenter, compute capability 10.0). memra builds for it and carries
receipts from September 2026, but the target is best effort: it is not maintained and no cell owed
on it will run (owner, 2026-11-04).

| | |
|---|---|
| **Build target** | `sm_100a`, auto-detected from compute capability 10.0; source build only |
| **Prebuilt** | no; `tools/install.sh` refuses `100a` before any download |
| **Push gate** | no (`tools/change-impact.toml`); CI compiles the `100a` cell of the arch matrix with layout checks |
| **Maintained** | no: best effort, the target is not push-gated ([GLM5-B200-DOORS](../decisions/GLM5-B200-DOORS.md) banner) |

## Device-keyed defaults

The `sm_100a` build keeps the defaults its receipts set: the GLM TP-2 plain route samples on the
device ([GLM5-TP-DEVICE-SAMPLER-DEFAULT](../decisions/GLM5-TP-DEVICE-SAMPLER-DEFAULT.md)), the
GLM-5.3 door decisions in [GLM5-B200-DOORS](../decisions/GLM5-B200-DOORS.md), and `MEMRA_FP8_MMQ`
and `MEMRA_MMQ_F8F4` stay explicit opt-ins ([FLAGS.md](../FLAGS.md)).

## Limits

- Expect no fix for a B200-only failure unless it also reaches a maintained target.
