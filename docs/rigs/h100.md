# H100

| | Recommended use |
|---|---|
| **Role** | Secondary, separately gated Hopper lane |
| **Build** | `sm_90a` |
| **Best fit** | Reproducing H100-qualified models and contributing to the Hopper backend |
| **Start with** | The model's H100 row and `tools/validate-h100.sh` |

H100 does not inherit Blackwell defaults. Its kernels, flags, measurements, and release battery
are separate. Read [ARCHITECTURE-H100.md](../../ARCHITECTURE-H100.md),
[models](../MODELS.md), and [testing](../TESTING.md#target-aware-release-evidence).
