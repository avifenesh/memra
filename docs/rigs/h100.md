# H100

| | Recommended use |
|---|---|
| **Role** | Secondary Hopper lane, source builds only since the 2026-09-02 arch retirement |
| **Build** | `sm_90a` (source: `MEMRA_CUDA_ARCH=90a`; no prebuilt ships) |
| **Best fit** | Reproducing H100-qualified models and contributing to the Hopper backend |
| **Start with** | The model's H100 row; the standing battery (`validate-h100.sh`) was retired with the lane — run kernel-check + `decode-batch-gate` + the graph gates directly |

H100 does not inherit Blackwell defaults. Its kernels, flags, measurements, and release battery
are separate. Read [ARCHITECTURE-H100.md](../../ARCHITECTURE-H100.md),
[models](../MODELS.md), and [testing](../TESTING.md#target-aware-release-evidence).
