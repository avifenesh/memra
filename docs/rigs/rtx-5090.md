# RTX 5090 and RTX 50-series

| | Recommended use |
|---|---|
| **Role** | Primary development and single-card tuning target |
| **Build** | `sm_120a` |
| **Best fit** | Supported models and context sizes that fit the card's VRAM |
| **Start with** | RTX 5090 blocks in the [cookbook](../COOKBOOK.md) |

Use the model's own 5090 configuration. Reduce context and session reservations to the workload
rather than copying a 96 GB configuration. Other RTX 50-series cards share the architecture but
need their own validation before inheriting performance claims.

MoE expert spill on this card: for an artifact the MoE slot cache door is qualified on, the gate binaries serve
spilled experts through the door by default, with its registered host pool and the in-token prefetch
([MOE-SPILL-DOOR-DEFAULT.md](../decisions/MOE-SPILL-DOOR-DEFAULT.md)). The door read flat against the legacy on
this card's deciding cell, and the prefetch won at the pressure shape here as on the PRO 6000.

Submit results with the [hardware validation template](../../.github/ISSUE_TEMPLATE/hardware-validation.md).
