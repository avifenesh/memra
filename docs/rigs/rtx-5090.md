# RTX 5090 and RTX 50-series

The consumer Blackwell card, memra's development and single-card tuning target. The measurements
here are on the 24 GB RTX 5090 Laptop GPU, except the device-penalty cell, which ran on a desktop
RTX 5090 (32 GB). The desktop card shares the build and the defaults keyed on every RTX 5090, not
the ones keyed on the laptop card.

| | |
|---|---|
| **Build target** | `sm_120a`, the default target; auto-detected from compute capability 12.0 (`crates/memra-engine/build.rs`) |
| **Prebuilt** | yes, the release tarball and `tools/install.sh` |
| **Push gate** | yes: an RTX 5090 cell record counts for `sm_120a` pushes, except for a default keyed on another card's name (`tools/change-impact.toml`) |
| **Maintained** | yes, the primary optimized target |
| **Topology** | one card (the multi-card planner caps the RTX 5090 at one card) |

## Limits

- Size context and sessions to the workload: a 96 GB configuration does not fit. The cookbook's
  24 GB envelope for Qwen3.8-27B is `MEMRA_CTX=8192` with eight sessions.
- Other RTX 50-series cards have no cell of their own, and the desktop RTX 5090 has only the
  device-penalty cell; they take the generic defaults, not the laptop-keyed ones.
